## PSTN/Voice 电话流程

- 初始 `Unsigned` 时不显示话务工具条，需要通过 Agent status menu 执行 Sign In 进入 Ready。
- 坐席 Ready 后不会再自动模拟来电。
- 点击左侧 `Channel Simulation > PSTN / Voice` 时，如果坐席为 Ready 且通话状态为 Idle，则进入 Incoming。
- Incoming 后 Inbound tab 打开，话务条 Answer 按钮亮起并闪烁。
- 点击 Answer 或等待既有 `autoAnswerSeconds` 倒计时后进入 Talking。
- Talking 后仍显示 Hold、Mute、Transfer、Hang Up。
- Hang Up 后进入 Not Ready/After Call Work，约 5 秒后恢复 Ready。
