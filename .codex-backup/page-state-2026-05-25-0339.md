## Live Chat 当前规则

- BankApp / WhatsApp 文字接入时，通过 `requestLiveChatWorkspace(sessionId)` 加入 active sessions 并从 `00:00` 开始运行计时。
- Live Chat tab 显示最长 active session duration；任何新 active session 进入都会短闪约 5 秒，即使当前正在 Live Chat tab。
- 客户列表只显示 active sessions，Webchat mock 继续隐藏。
- 客户列表 active/inactive 新接入 flash 视觉一致：浅 amber overlay + 细边框/内阴影，不改变行高。
- 点击/激活客户后，`readLiveChatSessionIds` 记录已读，头像右上 unread badge 消失；切到 Demo tab 再回 Live Chat 不会恢复 unread。
- End Service 会移除 session timing 和对应已读状态；无 active sessions 时 Live Chat tab 恢复无 duration。
- Conversation header timer 与列表/tab 使用同一份 runtime timing；warning / breach 时图标和文本一起变色。
