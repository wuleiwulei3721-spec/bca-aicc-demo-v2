## 通话接入阻塞状态

- Sign In 后 Ready + Idle 可以通过 `Channel Simulation > PSTN` 创建 `PSTN (mm:ss)` call tab。
- 当当前 `CallInteraction` 未结束且 `callStatus !== Idle` 时，再触发 PSTN / voice / video 不会创建新 call tab。
- PSTN 左侧菜单入口被阻塞时显示顶部 warning：
  - `Active call in progress. Please hang up before accepting another voice or video interaction.`
- BankApp Voice / Video 在客户侧 `Connected -> Agent Workspace` handoff 前检查当前未结束通话。
- BankApp Voice / Video 被阻塞时停留在 BankApp 当前步骤，不调用对应 request 方法，不进入 `agent-workspace`，在 AICC Process 控制区下方显示：
  - `Please hang up the current call before routing this interaction to Agent Workspace.`
- 切换 BankApp 渠道、Reset、Live Chat handoff 或成功 Voice / Video handoff 会清除 inline warning。
- Live Chat 路径不受当前未挂断通话限制影响。
