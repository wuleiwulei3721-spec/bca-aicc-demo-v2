## Call Tabs

- PSTN creates a `voice/pstn` interaction and displays `PSTN (mm:ss)`.
- BankApp Voice creates a `voice/bankapp-voice` interaction and displays `Voice Call (mm:ss)`.
- BankApp Video creates a `video/bankapp-video` interaction and displays `Video Call (mm:ss)`.
- Running call tabs use live duration from `startedAt`.
- Ended call tabs use frozen duration from `endedAt`.
- Current active call tabs are not closable.
- Ended call tabs are closable.
- New calls create new `call-n` tabs and do not overwrite old ended tabs.

## Toolbar And Presence

- `BasicLayout` still controls one active call state machine: `Incoming`, `Talking`, `Hold`, `Mute`, `Idle`.
- Answer marks the current call interaction `active`.
- Hang Up marks the current call interaction `ended`, clears current call linkage, hides OpenEye/share state, enters ACW, and returns to Ready after the existing delay.
- Old ended tabs do not keep the agent presence red.

## Video And Live Chat

- OpenEye and BankApp Video screen share are only shown for the current active video interaction.
- Ended video tabs do not display OpenEye.
- Live Chat remains unchanged as a fixed tab with active session list, runtime duration, SLA, and Webchat hidden.
