## Ready-aware 通话接入状态

- Voice/video handoff readiness：
  - `available`：Ready + Idle + 无未结束 call。
  - `active-call`：当前仍有未挂断电话、BankApp Voice 或 BankApp Video。
  - `not-ready`：没有未挂断 call，但坐席不是 Ready。
- `BasicLayout` 同步 readiness 到 store，PSTN 菜单与 BankApp Voice / Video handoff 使用同一判断。
- `active-call` 阻塞 PSTN 时显示：
  - `Active call in progress. Please hang up and wait until the agent is Ready before accepting another voice or video interaction.`
- `not-ready` 阻塞 PSTN 时显示：
  - `Agent is not Ready. Please switch to Ready before accepting another voice or video interaction.`
- BankApp Voice / Video `active-call` 阻塞时显示：
  - `Please hang up the current call and wait until the agent is Ready before routing this interaction to Agent Workspace.`
- BankApp Voice / Video `not-ready` 阻塞时显示：
  - `Agent must be Ready before routing this interaction to Agent Workspace.`
- Answer 按钮保持黄色背景 + 深色文字/图标。
